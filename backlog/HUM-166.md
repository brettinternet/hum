Problem: after editing `.env`, `.env.local`, or `processes.NAME.env`, `hum up` reports `already running; ready` and the process keeps its launch environment. Nothing tells the user or agent to restart. Edits to argv, cwd, or readiness already surface as `definition_drift` with `hum restart NAME` guidance.

Evidence: docs/design.md "Definition drift" lists environment as not compared, and "Privacy" says "There is no environment hash or drift field." README: "Changes apply on `hum restart`."

Direction (owner decision 2026-11-17: non-blocking warning):
- Compare only manifest contributions (resolved `environment.files` values and `processes.NAME.env`, including `null` removals), never inherited caller-shell variables, so opening a new terminal never reports a change.
- The comparison happens where the launch snapshot is held; no key, value, hash, or digest appears in any response, event, or log.
- `up` and `start` keep the running process and add a non-blocking warning, `environment changed; run hum restart NAME`, like `removed_definition`. Exit codes, `after` gating, and outcomes are unchanged. `restart` adopts the change as today.
- Revise the design.md Privacy and Definition drift sections to record that only the fact of a change is reported.

Non-goals: naming changed keys; any hash in responses; watching env files; automatic restart; blocking dependents.

Open questions before todo:
- Where the comparison runs. Drift is compared client-side today (`orchestrate.DefinitionChangedFields` against the response-safe `protocol.Process`, which has no env). The daemon keeps only the composed launch env (`app.StartRequest.Env`). Env drift therefore needs a request-only manifest contribution on start/restart, stored in the daemon record, plus a daemon-side check that returns only a boolean for an already-running `up`/`start`. Choose the request and the record field.
- The warning's field name in CLI JSON v1 and MCP (for example a `warnings` entry versus a boolean).
- Whether global records and records started by `hum run` (no manifest contribution) are excluded.
