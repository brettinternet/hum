Problem: after editing `.env`, `.env.local`, or `processes.NAME.env`, `hum up` reports `already running; ready` and the process keeps its launch environment. Nothing tells the user or agent to restart. Edits to argv, cwd, or readiness already surface as `definition_drift` with `hum restart NAME` guidance.

Evidence: docs/design.md "Definition drift" lists environment as not compared, and "Privacy" says "There is no environment hash or drift field." README: "Changes apply on `hum restart`."

Leading direction: compare the newly composed manifest environment with the record's saved launch environment inside the daemon and report only the field name `environment` in `changed_fields`. No key, value, or hash leaves the daemon. `restart` adopts the change, as for other drift.

Requires revising the design.md Privacy section to state that a field-name-only comparison exposes no names or values.

Non-goals: naming changed keys; any hash or digest in responses; watching env files; automatic restart.

Open questions before todo:
- With `inherit: true`, caller-shell variables differ per terminal (`PWD`, `SHLVL`, `TERM_SESSION_ID`, ...). Comparing the whole environment would report drift from every new terminal, so compare only manifest contributions (files and `env:`). Decide where that subset is kept.
- Whether env drift should fail `up` (exit 1) and block dependents like other drift, or be a non-blocking warning like `removed_definition`.

## Acceptance criteria

- [ ] docs/design.md lists environment as compared in Definition drift and its Privacy section states only the field name is reported; `rg -n "changed_fields" docs/design.md` prints the revised text.
- [ ] `mise exec go -- go test ./internal/orchestrate ./internal/cli ./internal/mcp -run "Test.*EnvironmentDrift" -count=1` exits 0 asserting that changing a value in a manifest env file makes `up` report `definition_drift` with `changed_fields: [environment]`, no response contains the key or value, `restart` adopts the change, and a differing caller-shell variable alone reports no drift.
