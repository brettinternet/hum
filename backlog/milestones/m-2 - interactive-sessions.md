## Description

Durable named supervision sessions that terminals and agents attach to across process incarnations, plus opt-in pseudo-terminal sessions so TTY-gated devtools prompt normally and can be answered from an attached run or a one-shot input write. Builds on the m-1 manifest and MCP adapter; keeps clean pipe-based logs as the default and excludes multiplexing, scrollback, tty by default, and Windows.
