## Description

Declared start ordering gated on readiness and opt-in relaunch after unexpected exit, so hum up brings a whole dev stack to a known state and keeps it there while every launch, exit, and backoff remains visible to attached terminals and agents. Builds on the m-2 interactive sessions; keeps exact-argv launches, bounded output, and the pipe-based default; excludes port or HTTP health checks, environment values or files, persistence across daemon replacement, restart of explicitly stopped processes, and Windows.
