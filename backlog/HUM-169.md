Problem: aggregate `hum status` and `hum list` show `exited` for every terminal record, so a clean exit, a crash, and a crash-looping process waiting to relaunch look the same.

Evidence (2026-11-17, built from 024ec7e): `web` (exit 1) and `flappy` (exit 2, `restart: on-failure`; named status said `relaunching in 1s (attempt 3/5)`) both showed `STATE exited`. The state cell is colored by exit code (`processStateStyle`), but its text omits the code, so it is invisible without color.

Outcome: the human STATE cell shows the exit code or signal for exited records (for example `exited 1`, `exited SIGKILL`) and marks pending recovery (for example `relaunching 3/5`).

Non-goals: no new columns; no change to JSON, sort order, or named status.

Open questions before todo: exact wording; whether HUM-106 width rules need adjustment.
