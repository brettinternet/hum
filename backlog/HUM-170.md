Problem: removing a worktree leaves its Hum processes running, and parallel worktrees multiply them. The Worktrunk example in examples/worktrees/wt.toml has a `pre-start` hook but no `pre-remove` hook that stops the worktree's processes.

Split from HUM-154 item 3 (owner decision 2026-11-17).

Scope:
- Add a `pre-remove` hook running `hum down` to examples/worktrees/wt.toml, so `wt remove` stops the worktree's project processes before the checkout disappears.
- Document it in examples/worktrees/README.md beside the `pre-start` hook, in one or two sentences.

Non-goals: no Hum code changes; no automatic stop when a project root disappears (rejected in HUM-154); no changes to the repository's own .config/wt.toml.
